# 🌟 Gemma Glance: Context-Aware Real-Time Knowledge Assistant

> **The Gemma 4 Good Hackathon Project**
> 
> 저사양 교육용 PC에서도 동작하는 문맥 기반 실시간 지식 보조 윈도우 툴

---

## 📝 프로젝트 개요 (Project Overview)

- **프로젝트 명**: Gemma Glance
- **정의**: 사용자가 읽고 있는 화면의 문맥을 실시간으로 분석하여, 어려운 용어나 지식을 즉시 설명해주는 로컬 AI 기반 오버레이 툴입니다.
- **타겟 페르소나**:
  - 🎓 **학생**: 전공 서적이나 논문의 어려운 학술 용어를 공부하는 학습자.
  - 👵 **노령층**: 디지털 기기 사용 중 발생하는 낯선 용어에 어려움을 느끼는 디지털 소외 계층.
  - 💻 **저사양 PC 사용자**: GPU가 없거나 인터넷 환경이 불안정하여 클라우드 AI 접근이 제한된 환경의 사용자.

---

## 🛠 기술 스택 (Tech Stack)

| 구분 | 기술 | 비고 |
| :--- | :--- | :--- |
| **운영체제** | Windows 11 | Win32 API 활용 |
| **언어** | Python 3.10+ | |
| **UI 프레임워크** | PySide6 | 깔끔하고 가벼운 오버레이 창 구현 |
| **텍스트 추출** | pywin32 / pyautogui | 마우스 위치 기반 컨텍스트 캡처 |
| **AI 엔진** | **LiteRT (Google AI Edge)** | CPU 환경 최적화 (Gemma 4 구동용) |
| **모델** | **Gemma 2 2B** | 4-bit Quantized (저사양 환경 최적화) |

## 🏗 핵심 아키텍처 (Core Architecture)

1. **Text Capture (텍스트 캡처)**
   - 사용자가 특정 단어 위에 마우스를 멈추거나 단축키를 입력.
   - 마우스 커서 좌표를 감지하여 Win32 API 또는 가벼운 OCR을 통해 주변 문맥(Context) 추출.
2. **Context Analysis (문맥 분석)**
   - 추출된 텍스트와 용어를 LiteRT 기반 Gemma 2 2B 모델에 전달.
   - **프롬프트 전략**: 
     - *"다음 문장에서 '양자화'라는 단어가 어떤 의미로 쓰였는지 초등학생도 이해할 수 있게 한 문장으로 설명해줘. [문장: ...]"*
3. **On-Screen Display (화면 표시)**
   - 마우스 커서 바로 옆에 작고 미려한 **투명 오버레이 창**을 생성.
   - 사용자 흐름을 방해하지 않는 깔끔한 UI로 결과 출력.

## 🚀 해커톤 소구 포인트 (Key Selling Points)

- **Digital Equity (디지털 형평성)**: 고가의 GPU 없이도 최신 대형 언어 모델(LLM)의 혜택을 모든 학생과 노령층에게 제공.
- **Privacy First (개인정보 보호)**: 모든 연산이 사용자 로컬 PC 내에서 이루어지므로, 사용자가 무엇을 읽고 있는지 외부로 절대 유출되지 않음.
- **Multimodal Expansion (확장성)**: 단순 텍스트를 넘어 이미지 속 글자나 도표 위에서도 Gemma의 시각 지능(Vision)을 활용할 수 있는 잠재력.
